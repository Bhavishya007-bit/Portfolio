# Bhavishya Gaur Data Science Portfolio

A responsive single-page portfolio for Bhavishya Gaur, a data science enthusiast pursuing Integrated M.Sc. in Life Sciences from NIT Rourkela.

## Included

- `index.html` - page structure and portfolio content
- `styles.css` - soothing dark palette and responsive layout
- `script.js` - project filters, counters, header behavior, and contact copy interaction
- `assets/data-science-workstation.png` - generated hero image saved into the project
